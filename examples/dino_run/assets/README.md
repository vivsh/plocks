# Dino Dash artwork

Seven original matching pixel-art pictures generated for this tutorial with OpenAI's
image-generation tool: dinosaur, cloud, bird, desert, cactus, rock, and coin.
These are independent designs; no Google or Chrome artwork is included.
The six isolated characters/objects have transparent backgrounds; desert is opaque.
Original generation prompts are in [prompts.json](prompts.json).

Use the PNGs to follow the lessons and remix the example. Resize them with Plocks'
`Costume.resized(...)`; the downloaded originals stay unchanged.
`pop.ogg` is the original short Plocks example tone, reused from Coin Quest.
