# Dojo Duel art

`dojo.png`, `teal_fighter_sheet.png`, and `ruby_fighter_sheet.png` are original
artwork created for this Plocks example. The fighter sheets have three frames in
order: standing, punch, kick. `dojo_theme.ogg` is looping music; `punch.ogg`,
`kick.ogg` and `hit.ogg` are short local effects. All audio files use OGG/Vorbis.
