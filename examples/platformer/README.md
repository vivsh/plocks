# 🪜 Sky Steps

Jump across gaps, ride the lift and reach the gold flag.

## Play

```sh
plocks run examples/platformer
```

**Arrows:** move · **Space:** jump · **R:** restart

## What you'll learn

- **Physics:** Plocks handles falling and landing for you.
- **Recipes:** `lift_trip` repeats a list of moves and waits.
- **Variables:** `spawn` remembers your checkpoint after a fall.

Start here! Read the setup, then `jump`, then `update`.

## Make it yours

1. Change the lift journey from 2 seconds to 3.
2. Move a ledge in the setup loop.
3. Change the jump impulse from 440 to 480.

**Your own project?** Copy this whole folder, keep `assets/` beside `main.py`,
and run `python main.py` with Plocks installed. It also works from another folder
using `python path/to/the/game/main.py`.
