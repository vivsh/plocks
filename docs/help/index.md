# Stuck? Try this 🔎

[Home](../index.md)

Change one thing at a time. Save your file, close the old game, and run it again.
Ask a grown-up if a message is confusing.

## Python cannot find plocks

Check that your project's virtual environment is switched on.
Follow [setup](../start/index.md) from inside the Plocks project folder.
For `python` not found or a blocked Windows command, ask for setup help.

## My picture or sound cannot be found

Keep the **whole assets folder** beside the example's Python file.
Check spelling, capitals and endings: `dinosaur.png` and `Dinosaur.PNG` can be
different names. Do not copy only `main.py` from a game folder.

## My keys or controller do nothing

Click the game window first. Check the keys listed in that game's README.
A jump might need to land before it can jump again.
Try the keyboard if a controller is not recognized.

## Python shows a red error

Read the last line first: it gives a clue. Check matching quotes and brackets.
Use four spaces beneath `def` and `if`, like the example.
Save the file before running it. If you ask for help, copy the whole error message.

## My drawing does not animate

Make the frames look different. Export both `hero.png` and `hero.json` again,
with matching names. Follow the [Pixelorama steps](../art/pixelorama.md).

## My map lost its pictures

Keep the exported map and its picture files together. Start with the prepared
workshop and change one thing. See [the Tiled steps](../art/tiled.md).

**Ready again?** [Pick your next activity](../activities/index.md).
