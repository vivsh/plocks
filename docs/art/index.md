# 🎨 Draw it. Build it. Play it.

[Home](../index.md)

Make a character in **Pixelorama**. Build its world in **Tiled**.
Then let Plocks put them on screen!

## Get ready

Ask a grown-up to help set up Plocks, **Pixelorama 1.2.2**, and **Tiled 1.12.2**.
These are the editor versions these activities use.

Copy the whole [Asset Workshop folder](../../examples/asset_workshop) to a new
folder called `my-game`. Keep its `assets` folder inside it.
Work on this copy so you can always start again.

```text
my-game/
    main.py
    assets/
        hero.png
        hero.json
        ground.png
        jungle.tmj
```

Try the ready-made game first. Open a terminal in `my-game` and run:

```sh
python main.py
```

**Player 1:** A / D to move, Space to jump.

**Player 2:** arrows to move, Enter to jump.
