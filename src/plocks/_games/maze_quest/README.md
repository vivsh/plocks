# Maze Quest

Collect four coins. Click floor tiles to choose a route around the walls.

```sh
plocks run maze_quest
```

**Controls:** Click to move. P pauses; click Continue or press Space to continue.

To change it:

```sh
plocks examples maze_quest --copy-to my-maze_quest
cd my-maze_quest
python main.py
```

**Python ideas:** tile maps, grid routes, touch events, a following camera, labels, health bars and buttons. Pictures are in `assets/` beside `main.py`.

**Try this:** change one speed, picture or distance. Save, run, and see what changed!
