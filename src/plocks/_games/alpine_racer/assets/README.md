# Alpine Racer artwork

Original Plocks racing artwork generated for this example: three orange-car
steering views, three rival cars, a conifer, chevron signs and a mountain panorama.
The right steering view mirrors the left so their size and baseline match.
The car PNGs are 192 by 128 pixels and have transparent backgrounds.

The two small road pictures contain the asphalt, kerbs and lane markings.
The game only loads these ready-made PNG files; it needs no Pillow artwork code.
`bump.ogg` is the existing original Plocks example tone.

These assets may be copied, changed and redistributed with your games.
