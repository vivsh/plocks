# Swing Lab

Watch the ball swing, cut its rope, and try again.

```sh
plocks run swing_lab
```

**Controls:** Space or the button cuts the rope. R resets the ball.

To change it:

```sh
plocks examples swing_lab --copy-to my-swing_lab
cd my-swing_lab
python main.py
```

**Python ideas:** physical ropes, fixed anchors, gravity, collision shapes, drawing and buttons. Pictures are in `assets/` beside `main.py`.

**Try this:** change one speed, picture or distance. Save, run, and see what changed!
